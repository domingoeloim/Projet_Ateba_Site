Nous vous offrons des formations innovantes et uniques en informatique.

Web development


Dans cette formation développeur web, vous allez apprendre JavaScript, le langage le plus recherché aujourd'hui, et les librairies qui l'accompagnent, de Bootstrap à Node.Js. Vous aurez une maîtrise complète des technologies du moment pour coder des sites web, des pages web interactives. Vous maîtriserez les outils et les méthodes pour travail comme les meilleurs développeurs web.

Web Design UX/UI

Dans notre formation web design UX/UI nous apprenons aux étudiants à créer des produits numériques conviviaux (User-friendly). Le côté UX traite de l'expérience globale de l'utilisateur avec un produit ou un service. UI (L’interface utilisateur) se concentre sur l'apparence et les fonctions du produit ou du service. Ateba Coding Bootcamp offrent une formation à la fois sur l'UX et l'UI.

Développement Web & Mobile
